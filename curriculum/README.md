# Curriculum research (Nigerian degree programmes, year 1 to final year)

Course lists for 20 departments, held in git for later propagation into the app.
Nothing here touches the database, `src/lib/catalog.ts` or `supabase/migrations`.

## Layout

| Path | What it is | Edit by hand? |
|---|---|---|
| `curriculum/<department>.txt` | One line per course: `year\|code\|name\|c-or-e` | Yes (source of truth) |
| `curriculum/shared/*.txt` | Courses taken by many departments (GST/ENT, science year 1, engineering core) | Yes |
| `curriculum/profiles/*.txt` | One line per distinct course title: `title\|general name\|summary\|psychometric tags\|industrial tags` | Yes |
| `curriculum/faculties.json` | Faculty to department map, pending departments, open decisions | Yes |
| `curriculum/sources/code-index.json` | Every code/title/unit triple read from the sources (1,708 entries, 723 with units) | Generated by research |
| `curriculum/build/*.json` | Final per-department output for consumers | **No. Run `python3 scripts/build-curriculum.py`** |

`python3 scripts/build-curriculum.py --strict` exits non-zero on a missing profile or a slug clash.
`--list-missing` prints titles that have no profile.

## What each built course carries

`year`, `code`, `name`, `kind` (core or elective), `slug`, `general_name` (composite title),
`known_codes` (every code seen across sources, units in brackets, e.g. `PHY101 (2), PHY111 (3)`),
`aliases` (each code with units and source), `summary` (course scheme),
`psychometric` and `industrial` (skills tested or built), `shared_with` (other departments that take the same course).

Slug rule matches migration 0016: `lower(regexp_replace(coalesce(code,name),'[^a-zA-Z0-9]+','-','g'))`, unique per department.
Codes are stored without spaces (`CSC101`), as in the existing database rows.

## Skill vocabulary

Psychometric: NUM numerical, VER verbal, LOG abstract and logical reasoning, SPA spatial, MEM memory and recall, DET attention to detail, MEC mechanical reasoning, CRT critical judgement.
Industrial: LAB laboratory technique, PRG programming, CAD drafting and CAD, DES engineering design, HSE health and safety, PM project and operations management, COM communication, CLN clinical practice, DAT data analysis, ETH professional ethics, ENT entrepreneurship, RES research method, FLD fieldwork, MFG manufacturing and processing, SEC security practice, FIN finance and costing, LEG legal and regulatory, CUS client and patient care.

6. Linguistics has no department in the app yet.

## Year 1 and year 2 sharing

`shared_with` lists the other departments taking the same course. 100 courses are shared by two or more departments.
Year 1 is shared by all science-based programmes (MTH, PHY, CHM, BIO, COS) and by every programme through GST. Engineering departments share the GET core through year 5.
A question written for a shared course should be stored once and linked from each department.

## Propagating into the database later

1. Read `curriculum/build/<department>.json`.
2. Insert only into years listed in `complete_years`.
3. Each file's `supersedes_placeholders` lists existing skeleton rows that the research replaces. Retire only rows that no question references.
4. Never delete the 8 question-linked skeleton courses (foreign keys cascade to questions).
5. Check slugs against migration 0016 before inserting.
6. Migrations stay in the lane rules in `handoff/LANES.md`.
